# Gene-set files (not included)

MSigDB gene sets are not redistributed here (MSigDB terms of use; the KEGG
legacy collection is additionally subject to the KEGG license). Download these
two files from MSigDB release **v2023.2.Hs** (Entrez gene IDs) and place them in
this folder:

| File | MSigDB collection |
|---|---|
| `h.all.v2023.2.Hs.entrez.gmt` | H: Hallmark gene sets |
| `c2.cp.kegg_legacy.v2023.2.Hs.entrez.gmt` | C2 CP: KEGG_LEGACY |

Download page (free registration required):
https://www.gsea-msigdb.org/gsea/msigdb/human/collections.jsp

The file names are set in `config.py` (`GMTS`).
