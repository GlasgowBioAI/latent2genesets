# External labels for the within-group case studies

These labels define the ten phenotype contrasts used in the within-group case
studies (Supplementary Table S4). They are external annotations and are not
derived from the expression matrices. They are used only to build the
within-group differential-expression references and are never provided to the
dimensionality-reduction methods.

TCGA labels were retrieved from cBioPortal's public REST API
(`https://www.cbioportal.org/api`) and matched to the TCGA sample cohort by
15-character sample barcode (e.g. `TCGA-A2-A0T2-01`). GTEx labels were built
from the GTEx v8 public subject annotations. Samples without a usable label
are NaN (TCGA) or absent (GTEx) and are excluded from reference construction.

| File | Contrast(s) | Case vs control |
|---|---|---|
| `brca_er_pr_her2.csv` | BRCA ER, PR, HER2 | Positive vs Negative |
| `coad_msi.csv` | COAD MSI | MSI-H vs MSS |
| `hnsc_hpv.csv` | HNSC HPV | HPV+ vs HPV- |
| `thca_braf.csv` | THCA BRAF | p.V600 hotspot vs wild-type |
| `luad_egfr.csv` | LUAD EGFR | mutant vs wild-type |
| `gtex_age.csv` | Age in Muscle - Skeletal and Artery - Tibial | 20-39 vs 60-79 |
| `gtex_dthhrdy.csv` | Hardy scale in Muscle - Skeletal | fast (0-1) vs slow death (4) |

## brca_er_pr_her2.csv

Source study: `brca_tcga_pub` (`clinical-data?clinicalDataType=SAMPLE`).
- `er_binary`: Positive/Negative (NaN if not performed, indeterminate or missing)
- `pr_binary`: Positive/Negative (NaN if indeterminate or missing)
- `her2_binary`: Positive/Negative (NaN if equivocal or missing)

## coad_msi.csv

Source study: `coadread_tcga_pan_can_atlas_2018` (MSIsensor score).
`msi_binary`: MSIsensor score >= 10 -> "MSI-H", < 10 -> "MSS", NaN if the
score is missing. Raw `MSI_SENSOR_SCORE` and `MSI_SCORE_MANTIS` are included.

## hnsc_hpv.csv

Source study: `hnsc_tcga_pub`. `HPV_STATUS` is a patient-level field, joined
by 12-character patient barcode. Regenerated by `pipeline/04_phenotype/fetch_labels.py`.

## thca_braf.csv, luad_egfr.csv

Derived from mutation calls in `thca_tcga_pan_can_atlas_2018` (BRAF,
Entrez 673) and `luad_tcga_pan_can_atlas_2018` (EGFR, Entrez 1956),
restricted to each study's sequenced sample list.
- `braf_binary`: "Mutant" if the sample carries a BRAF p.V600 hotspot mutation,
  "WT" if sequenced with no BRAF mutation, NaN if it carries another BRAF mutation.
- `egfr_binary`: "Mutant" if the sample carries any EGFR mutation call, "WT"
  if sequenced with none.

Regenerated by `pipeline/04_phenotype/fetch_labels_thca_luad.py`.

## gtex_age.csv, gtex_dthhrdy.csv

Built from `GTEx_Analysis_v8_Annotations_SubjectPhenotypesDS.txt`, joined by
donor ID. Intermediate categories are dropped rather than assigned to either
side:
- `age_binary`: "Young" (20-29, 30-39) vs "Old" (60-69, 70-79)
- `dthhrdy_binary`: "Fast" (Hardy scale 0-1) vs "Slow" (Hardy scale 4)

Regenerated by `pipeline/04_phenotype/build_gtex_labels.py`.
