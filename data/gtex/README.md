# GTEx sample annotations (not included)

Download `GTEx_Analysis_v8_Annotations_SampleAttributesDS.txt` from the
[GTEx Portal](https://www.gtexportal.org/home/datasets) (v8, open access) and place it in
this folder. It supplies the tissue label (`SMTSD`) of every GTEx sample.

This is the default location (`config.GTEX_SAMPLE_ATTR`). To keep the file elsewhere, set
`LATENT2GENESETS_GTEX_SAMPLE_ATTR` to its path.
